# 도메인 문서 양식

프로젝트 셋업 때 도메인을 나누고(표준 틀 5절 체크리스트 3번), 아래 두 가지를 만든다. 모든 프로젝트가 이 양식을 복사해 쓴다.

```
개발/도메인/
├── 도메인 목록.md          ← 아래 "도메인 목록" 부분
├── 대여/대여.md            ← 아래 "도메인 문서" 부분
└── 도서/도서.md
```

도메인 문서는 문서만 보고 그 도메인을 파악하기 위한 정리본이다. 코드 동작의 정본은 저장소 `docs/specs/<도메인>.md`이고, 이 문서는 기능 완료 때 코디네이터가 그 내용을 가져와 요약한다. 둘이 다르면 저장소가 맞다(표준 틀 4.3절).

---

## 도메인 목록

```markdown
---
type: domain-index
updated: YYYY-MM-DD
---

# 도메인 목록

도메인을 새로 만들거나 합치면 결정 기록(`개발/결정/`)을 남기고 이 표를 고친다.

| 도메인 | 책임(한 줄) | 모듈 저장소 | API 자원 | 오류 코드 접두어 | 현행 명세 | 기획 / 디자인 |
|---|---|---|---|---|---|---|
| [[대여]] | 예약·대여·반납 규칙 | `book-api` | `/v1/rentals` | `RENTAL` | `docs/specs/대여.md` | `기획/대여/` · `제품 디자인/대여/` |
```
