# 기능 문서 양식

Jira 에픽 하나마다 이 문서를 하나 만든다. 그 에픽의 스토리와 하위 작업(기획·디자인·개발·QA)을 한곳에서 보는 표지다(표준 틀 4.3절).

예: 에픽 `BOOK-10` "대여 예약"

```
<프로젝트>/기능/
└── BOOK-10 대여 예약/          ← 에픽 폴더 (Jira가 없으면 E-<번호>)
    ├── 대여 예약.md            ← 이 양식으로 쓴 기능 문서
    ├── 기획/ 디자인/            ← 기획·디자인 하위 작업의 이번 변경분 초안
    ├── BOOK-14 예약 API/       ← 개발 하위 작업 = PR 하나 = ticket-workflow 산출물
    └── BOOK-15 예약 화면 구현/
```

스토리 폴더는 만들지 않는다. 이 문서는 기능이 끝나면 고치지 않는다. 지금 어떻게 동작하는지는 저장소 현행 명세(`docs/specs/<도메인>.md`)와 옵시디안 도메인 문서(`개발/도메인/<도메인>/`)가 맡는다.

v0.10 전 이름은 "기능 스펙 양식"이었고 `spec.md`·`plan.md`·`tasks.md` 세 파일이었다. "스펙(명세)"은 이제 현행 명세만 가리킨다. 계획과 작업 목록은 개발 하위 작업의 설계·구현 문서가 맡는다.
