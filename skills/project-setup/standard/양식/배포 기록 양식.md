# 배포 기록 양식

모든 프로젝트가 이 양식을 복사해 `개발/운영/배포/YYYY-MM-DD <정기|긴급>.md`로 쓴다. 프로젝트별 사본 양식은 만들지 않는다. 모듈 목록·순서처럼 프로젝트마다 다른 내용은 프로젝트 입구 문서나 `개발/운영/` 런북을 따른다.

---

```markdown
---
type: deploy
date: YYYY-MM-DD
kind: 정기 | 긴급
version: vX.Y.Z
status: 예정 | 완료 | 취소 | 되돌림
---

## 순서와 확인 항목

순서: DB(스키마 변경) → 백엔드 → 프론트. 각 단계는 `deploy/deploy.sh <태그>`.

- [ ] 배포 전: `scripts/check.sh` 통과, 태그 생성, 공통 라이브러리 버전 확인
- [ ] DB: 스키마 변경 적용, 이전 버전 코드와 호환 확인
- [ ] 백엔드: `GET /health` 정상
- [ ] 프론트: 주요 화면 확인
- [ ] 배포 후: 오류 알림·로그 확인(30분)

## 되돌리기

이전 태그: `vX.Y.Z`. 같은 스크립트를 이전 태그로 다시 돌린다. 데이터 되돌림이 필요하면 방법을 적는다.

- 결과: 완료 / 취소(이유) / 되돌림(이유)
- 남은 일: (대기 목록으로 넘긴 티켓)
```
