# AI 협업과 LLM 에이전트

> [[30 Areas/Development Standard/개발 규약|개발 규약]] 10절. 버전과 변경 이력은 개발 규약 입구 문서에 둔다.

- 저장소 `AGENTS.md`에는 네 가지만 쓴다: 따르는 틀 버전과 경로, 프로젝트 문서 경로(옵시디안), 주요 명령, 이 모듈 고유 규칙과 사람 확인 지점.
- **사람 확인 지점:** 운영 배포, 비밀정보, 외부로 나가는 발송, 돈, 데이터 삭제. AI는 이 일을 사람 확인 없이 하지 않는다.
- AI가 만든 결과의 책임은 리뷰한 사람에게 있다.
- **운영에서 LLM 에이전트가 화면·브라우저를 조작할 때**
  - 동작마다 로그와 스크린샷을 남기고, 보관 기간을 정한다.
  - 필요한 도구만 좁게 준다(예: 정해진 앱·사이트만, 정해진 동작만).
  - 확신이 없거나 화면이 예상과 다르면 멈추고 사람에게 알린다. 추측으로 계속하지 않는다.
  - 한 번에 하나씩 돌리고, 같은 일을 대량으로 반복하지 않는다.
  - 비밀번호·키는 에이전트에게 보여 주지 않는다. 로그인은 사람이 해 둔 세션을 쓴다.
