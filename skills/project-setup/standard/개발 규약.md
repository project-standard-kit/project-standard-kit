# 개발 규약 (v0.13)

> 표기: [FACT] 직접 확인, [CLAIM] 출처의 주장, [INFERENCE] 이 문서의 판단. 기준일 2026-10-26.
> 모든 프로젝트와 모듈에 언어와 상관없이 적용한다. 규약 문서마다 세 부분이 있다: **공통 규칙**(모든 프로젝트가 그대로 따르는 것, 언어와 상관없는 컨벤션은 자세히), **프로젝트 셋업 때 정할 것**(도구·인프라처럼 프로젝트마다 다른 자리), **예**(팀 기본값). 정할 것은 셋업 때 `project-setup` 스킬이 [[30 Areas/Development Standard/양식/프로젝트 개발 규약 양식|프로젝트 개발 규약 양식]]의 질문지로 리더에게 권장안과 함께 묻고, 답을 프로젝트 `개발/<프로젝트> 개발 규약.md`에 적는다. 저장소에는 이 문서를 복사하지 않고 `AGENTS.md`에서 가리킨다.
